# Smartsheets

Set up the Smartsheets source connector by following this guide.

## Prerequisites

To configure the Smartsheet Source for syncs, you'll need:

- A Smartsheets API access token generated by a Smartsheets user with at least **read** access
- The ID of the spreadsheet you want to sync

## Step 1: Set up Smartsheets

### Get an API access token

Generate an API key from your Smartsheet webapp session by selecting:

- Account (top-right icon)
- Apps & Integrations
- API Access
- Generate new access token

For guidance on advanced authorisation flows, see [this](https://www.smartsheet.com/content-center/best-practices/tips-tricks/api-getting-started).

### Find your spreadsheet ID

You'll also need the ID of the Spreadsheet you want to sync. Unlike Google Sheets, this ID isn't in the URL. Find the required spreadsheet ID in your Smartsheet app session by selecting:

- File
- Properties

## Step 2: Set up the connector

**For Airbyte Cloud:**

1. [Log into your Airbyte Cloud](https://cloud.airbyte.com/workspaces) account.
2. In the left navigation bar, click Sources. In the top-right corner, click **+new source**.
3. On the Set up the source page, name the Smartsheets connector. Then select **Smartsheets** from the Source type dropdown.
4. Authenticate through OAuth2.0 using the API access token from Prerequisites.
5. Enter the start date and the ID of the spreadsheet you want to sync.
6. Submit the form.

**For Airbyte Open Source:**

1. Go to the Airbyte Open Source dashboard.
2. Set the name for your source.
3. Enter the API access token from Prerequisites.
4. Enter the ID of the spreadsheet you want to sync.
5. Enter a start sync date.
6. Click **Set up source**.

## Supported sync modes

The Smartsheets source connector supports these [sync modes](https://docs.airbyte.com/cloud/core-concepts#connection-sync-modes):

- Full Refresh | Overwrite
- Full Refresh | Append
- Incremental | Append
- Incremental | Deduped

## Performance considerations

At the time of writing, the [Smartsheets API rate limit](https://developers.smartsheet.com/blog/smartsheet-api-best-practices#be-practical-adhere-to-rate-limiting-guidelines) is 300 requests per minute for each API access token.

## Supported streams

This source provides one stream for each spreadsheet. Its dynamic schema depends on your spreadsheet structure.
For example, a spreadsheet named `Customers` creates a stream with the same name. Its properties follow the Data type map shown in [below](https://docs.airbyte.com/integrations/sources/smartsheets/#data-type-map).

## Key details

The Smartsheet Source pulls data from one Smartsheet spreadsheet. Unlike Google Sheets, Smartsheets allows only one sheet per Smartsheet. Each Airbyte connector instance can therefore sync only one sheet at a time. To replicate multiple spreadsheets, create multiple Smartsheet Source instances in Airbyte. You can reuse the API token across every sheet you need to sync.

**Note: Column headers must contain only alphanumeric characters or `_` , as specified in the** [**Airbyte Protocol**](../../platform/understanding-airbyte/airbyte-protocol).

## Data type map

This connector's data type mapping is based on the Smartsheet [documentation](https://smartsheet-platform.github.io/api-docs/index.html?python#column-types).

**NOTE**: For column data types interpreted by Smartsheets, except `DATE` and `DATETIME`, the connector assumes a `string` type. In this case, Airbyte doesn't require the `format` field.

| Integration Type | Airbyte Type | Airbyte Format      |
| :--------------- | :----------- | :------------------ |
| `TEXT_NUMBER`    | `string`     |                     |
| `DATE`           | `string`     | `format: date`      |
| `DATETIME`       | `string`     | `format: date-time` |
| `anything else`  | `string`     |                     |

Smartsheets supports other, more complex column data types, such as Predecessor and Dropdown List. This connector supports only their `string` representation.

## IP allow list

If you use Airbyte Cloud and restrict access to specific IPs, add the [Airbyte Cloud IP addresses](https://docs.airbyte.com/platform/operating-airbyte/ip-allowlist) to your allow list.
