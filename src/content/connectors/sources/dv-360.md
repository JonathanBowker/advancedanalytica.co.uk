# Display & Video 360

:::warning

## Deprecation notice

The Display & Video 360 source connector is scheduled for deprecation on March 5th, 2024. It is incompatible with upcoming platform updates before the launch of Airbyte 1.0. After deprecation, you can no longer use it in Airbyte, and it will receive no support.

This connector doesn't support new per-stream features that are vital for data integrity during Airbyte synchronisation. Without these features, Airbyte can't enforce its reliability and correctness standards for data syncing operations.

### Recommended actions

To continue syncing this data, you can create a custom connector as an alternative. For guidance, visit [Custom Connector documentation](https://docs.airbyte.com/connector-development/).

:::

Google DoubleClick Bid Manager (DBM) is the API for managing Queries and retrieving Reports from Display & Video 360.

DoubleClick Bid Manager API `v1.1` is the latest available and recommended version.

See [Link](https://developers.google.com/bid-manager/guides/getting-started-api) for the official documentation

## Features

| Feature           | Supported? |
| :---------------- | :--------- |
| Full Refresh Sync | Yes        |
| Incremental Sync  | Yes        |

## Supported tables

You can sync the following tables and their data:

- Audience Composition
- Floodlight
- Reach
- Standard
- Unique Reach Audience

**Note**: Build your desired report in the UI first to avoid errors. Several limitations and requirements apply to reporting types, filters, dimensions and metrics. These include valid combinations of metrics and dimensions.

#### Available filters and metrics

You can find the available filters and metrics in [page](https://developers.google.com/bid-manager/v1.1/filters-metrics).

## Get started \(Airbyte-Cloud\)

1. Click `Authenticate your Display & Video 360 account` to sign in with Google and authorise your account.
2. Get the partner ID for your account.
3. Enter a start date and, optionally, an end date and filters. Check [Queries documentation](https://developers.google.com/bid-manager/v1.1/queries).
4. Setup is complete.

## Get started \(Airbyte Open Source\)

#### Requirements

Use [setup tool](https://console.developers.google.com/start/api?id=doubleclickbidmanager&credential=client_key) to create credentials and enable the DBM API in the Google API Console.

- access_token
- refresh_token
- token_uri
- client_id
- client_secret
- start_date
- end_date
- partner_id
- filters

#### Setup guide

- [Getting Started guide](https://developers.google.com/bid-manager/guides/getting-started-api)

- [Using OAuth 2.0 to Access Google APIs](https://developers.google.com/identity/protocols/oauth2/web-server#enable-apis)

## Rate limits and performance \(Airbyte Open Source\)

The DBM API limits constrain this source. You can learn more about these limits in [Display & Video 360 docs](https://developers.google.com/bid-manager/guides/scheduled-reports/best-practices#consider_reporting_quotas).
