# The Woodland Carbon Code registered before you started planting. Did yours?

Woodland carbon value can be lost before the first tree goes in the ground.

Under current Woodland Carbon Code guidance, projects must be registered before work begins on site. That includes ground preparation, fencing, deer control, or planting.

For estates running active restocking, new woodland creation, natural regeneration, or mixed land-use projects, this timing point matters. It is not a minor administrative detail. It can decide whether future carbon value is available at all.

> A missed registration window is not a paperwork delay. It is a commercial loss.

## Why the timing is easy to miss

Estate work often moves through practical channels first. A contractor is booked, fencing starts, ground is prepared, planting windows open, and the project becomes real on the land before the paperwork has caught up.

That rhythm makes sense operationally. It is risky commercially.

Carbon standards require evidence that the project was eligible, additional, properly registered, and independently validated or verified. If the scheme requires registration before work begins, then the estate needs a system that knows when "work begins" for each project.

## The AI role

An AI-driven estate system can maintain a pre-start register for natural capital projects. Before any physical work begins, it can check whether the project has the necessary records and approvals.

| Pre-start check | Why it matters |
|---|---|
| Land parcel and boundary confirmed | Defines the project area |
| Scheme eligibility assessed | Reduces wasted project effort |
| Registration completed | Protects future carbon value |
| Baseline evidence captured | Supports validation and later verification |
| Contractor start date logged | Creates a defensible project timeline |
| Escalation triggered before work starts | Prevents accidental loss of value |

## The governance point

No estate manager should have to hold every registration condition in their head.

The system should hold the rule. The system should watch the date. The system should ask for the missing evidence before the deadline passes.

Human advisers still make professional judgements. AI handles the monitoring burden and makes sure the right question is asked at the right time.

## From risk to routine

The goal is to make registration discipline routine. Every woodland project should move through a controlled pre-start sequence before physical work begins. If the project does not need Woodland Carbon Code registration, the system should record that decision and the reason. If it does, the system should not let the estate drift past the point of no return.

That is how carbon governance becomes part of estate operations rather than a separate scramble.
